BIRTHDAY WEBSITE
=================

Files:
- index.html
- style.css
- script.js

HOW TO RUN:
1. Put all three files in the same folder.
2. Open the folder in VS Code.
3. Double-click index.html, OR use the VS Code "Live Server" extension and click "Go Live".
4. The website will open in your browser.

CUSTOMIZE:
- Change "08.27" in index.html to the birthday/date you want.
- Change the main message in the <section class="message">.
- Change "Happy Birthday" if you want a name included.
- The fonts load from Google Fonts, so an internet connection is needed for the exact typography.
  Everything else works locally.

The site is responsive and includes a subtle confetti animation when the surprise button is clicked.
